# 基于 Vue3 + Vite 打造的轻量级可视化网页编辑器，支持组件拖拽、实时预览与 HTML 导出。
##  项目状态
早期 MVP 原型，整体开发进度约 40%，核心编辑功能可用（拖拽、吸附、撤销/重做、JSON/HTML/Vue 导出、预设模板、后端代码生成、本地草稿自动保存）。"AI 辅助建站"功能正在开发中。代码未做全面优化、边界校验及生产环境适配，请勿直接用于线上生产项目。
## 功能特性
- 拖拽式编辑：通过拖拽组件到画布快速搭建页面
- 丰富的组件库：内置文本、图片、按钮、表单、导航等常用组件
- 多选对齐与分布：左/右/居中、顶/底/垂直居中、水平/垂直等距（一次撤销可回退）
- 图层面板：拖拽排序、显示/隐藏、锁定、重命名，hover 与画布联动
- 复制粘贴与快捷键：`Ctrl+C/V/D/A`、方向键微调、`Ctrl+S` 保存、多选删除
- 实时预览：所见即所得，编辑效果即时展示
- 一键导出：打包生成可独立运行的纯 HTML 文件，另支持 Vue 单文件/工程导出
- 预设模板：内置多套页面模板与常用布局，快速起步
- 本地图片支持：上传本地图片并随同页面一起导出
- 草稿自动保存：编辑内容防抖自动保存到浏览器本地，刷新不丢失
- 数据契约：组件 Schema 统一校验（导入时自动过滤未知类型）
- AI 辅助建站：在画布里摆放好组件后，点击工具栏"🤖 AI 生成"，由 AI 补全为完整网页（可回画布继续编辑，或直接导出完整 HTML / Vue）
## 技术栈
- 前端框架：Vue 3 (Composition API)
- 构建工具：Vite
- 状态管理：Vue3 Reactive
- 样式方案：CSS3 + Scoped Styles
- 文件导出：JSZip + FileSaver
## 安装和运行

# 安装项目依赖
npm install

# 启动本地开发服务（浏览器自动打开）
npm run dev -- --open

# 或直接双击项目根目录下的 启动编辑器.bat（一键：检测 Node、首次自动装依赖、启动并打开浏览器）

# 打包构建生产版本
npm run build

# 本地预览打包产物
npm run preview

> **开发小贴士**：修改 `src/stores/*.js` 这类普通 JS 模块后，Vite 热更新偶尔会出现
> 「组件已更新但 store 模块未同步」的情况，表现为点击无响应 / 组件拖不动。
> 遇到这类异常先**硬刷新页面（Ctrl + Shift + R）**，仍不行则重启 dev 服务器。

快速开始
0. （推荐）双击项目根目录的 `启动编辑器.bat`，脚本会自动检测 Node、首次运行自动安装依赖、启动开发服务器并打开浏览器
1. 启动项目后，从左侧组件栏选择组件
2. 拖拽组件至中间画布完成布局
3. 在右侧属性面板修改组件内容、样式
4. 点击预览按钮查看最终效果
5. 点击导出，生成并下载完整 HTML 文件

AI 辅助建站（Beta）
1. 在画布中先摆放几个组件作为"骨架"（或直接应用左侧的预设页面）
2. 点击工具栏"🤖 AI 生成"打开面板
3. 在面板中选择服务商（支持 **DeepSeek 官方** 与 **OpenCode Go** 两家，均为 OpenAI 兼容接口），点击"📄 选择 Key 文件"从本地文本文件加载 API Key，可先点"测试连接"
4. 输入页面类型与你的要求，选择风格、生成模式（补全/重写/追加）与输出方式
5. 点击"开始 AI 生成"，在结果预览中确认后点"应用"

### 两条产出链路（重要）
编辑器画布是**绝对坐标**模型（每个组件记录 left/top 像素），它只适合在编辑器里所见即所得地摆放；
真正交付的网页不应该由绝对坐标翻译而来。因此 AI 面板提供两类输出：

| 输出方式 | 说明 | 适用场景 |
| --- | --- | --- |
| **回到画布继续编辑** | AI 在画布坐标系内补全页面，应用后可继续拖拽微调（可 Ctrl+Z 撤销） | 还想继续手工调整 |
| **直接生成成品网页（AI 写 HTML/CSS）** | AI 把画布当成**需求草图**，重新输出一份语义化标签 + flex/grid 文档流 + 响应式的完整 HTML（不含绝对定位），直接下载 `index.html` | 要交付/部署的正式页面（推荐） |
| 按画布像素布局导出 HTML / Vue | 把画布上的绝对像素位置原样翻译成 HTML / Vue 工程 | 需要 1:1 还原你摆放的效果 |

### 多画布 / 多页面

编辑器采用 **项目 → 画布 → 页面 → 组件** 的四层结构：

- **画布（Canvas）**：一个完全独立的设计空间（可理解为一个站点）。不同画布之间的页面与组件互不影响，
  适合同时做多套互不相干的页面（如"官网"和"活动页"）
- **页面（Page）**：画布内的一个网页。工具栏下方有画布选择器与页面标签页：
  - 单击标签切换页面，**双击标签重命名**，`×` 删除页面（每个画布至少保留一页）
  - `＋ 页面` 新建、`⧉ 复制` 复制当前页面（含全部组件，组件 id 自动重新生成）
- **页面间跳转**：在属性面板的「🔗 页面跳转」里选择目标页面即可
  （文字/图片/按钮，以及导航菜单项、面包屑、列表项、轮播图的链接都支持）。
  编辑器内部记录为 `#page:<页面ID>`，**导出整站时会自动重写为对应页面的文件名**

**导出整站**：工具栏「导出整站」把当前画布的**所有页面**打包成一个 ZIP
（第一个页面为 `index.html`，其余按页面名生成如 `about-us.html`，中文页面名回退为 `page-N.html`），
页面之间的跳转链接会互相串联，解压即可直接部署。含本地图片时 `images/` 目录一并打包。

> 草稿会保存整个项目（所有画布与页面）以及当前停留的画布/页面；旧版单页草稿会自动迁移。

### AI 页面感知与多页生成

AI 生成现在**知道本站有哪些页面**，并且可以**一次生成整个站点**：

| 生成范围 | 说明 |
| --- | --- |
| **只生成当前页面** | 只处理当前打开的页面，但 Prompt 里会带上「本站页面清单」，因此 AI 写的导航栏 / 页脚会自动指向真实页面（内部记为 `#page:<页面名>`，应用后解析为页面 ID） |
| **生成整个站点（多个页面）** | 一次让 AI 规划并生成多个页面（输出 `{ siteName, pages: [...] }`），应用后自动在当前画布创建这些页面，并把页面之间的跳转链接互相关联 |

- 可设「期望页面数」（1~12）与「替换当前画布已有页面」——默认**追加**，不删除已有内容
- AI 会为每个页面给出**英文 slug**（如 `products`），导出整站时用作文件名：
  `index.html`、`products.html`、`about.html`……（中文页面名不再退化成 `page-2.html`）
- 每一页都会**独立执行 Schema 校验与重叠自动修复**
- 应用后提示会显示：创建了几个页面、串联了多少个页面跳转链接
- 页面名重复时自动加序号（避免跳转链接产生歧义）

### 组件重叠会自动修复
AI 常把"绝对定位画布"误当成文档流，把多个组件写在同一个 `top` 上，导致页面上糊成一团。
系统在 AI 结果进入画布前会做一次几何修复（`src/utils/layoutRepair.js`）：

- 容器内子元素互相重叠时逐行排开，并自动撑高容器
- 顶层区块互相重叠时按阅读顺序整体下移
- 保持本来正确的并排（同一行 left 不相交的元素）不被拆散
- 按内容自动补足页面高度

修复后会在面板上提示"已自动修复布局重叠（N 处 → 0 处）"。同时 Prompt 里也写入了硬性坐标规则，
从源头减少 AI 复用同一 `top` 的情况。

注意：
- API Key 通过本地文本文件加载（或手动输入），**只保存在浏览器内存中（本次会话有效），不会写入 localStorage / 页面代码**；刷新页面后需重新加载。Key 文件格式：一行 `sk-xxx`，或 `KEY=sk-xxx`，可含 `#` 注释与空行
- 默认服务商为 DeepSeek 官方，默认模型为 DeepSeek V4.1（官方 API 模型 ID：`deepseek-flash`）；切换服务商时 API 地址与模型会自动切换
- **DeepSeek 官方**：前往 https://platform.deepseek.com 获取 API Key
- **OpenCode Go**：每月 $10 的订阅服务，前往 https://opencode.ai/auth 订阅并复制 API Key（模型列表见 https://opencode.ai/docs/zh-cn/go/）
- **跨域（CORS）已自动处理**：第三方 AI 接口不允许浏览器直连，因此本地运行时前端改为请求同源路径 `/api-proxy/...`，由 Vite 开发/预览服务器转发到真实端点（配置见 `vite.config.js`）。请务必用 `npm run dev` / `npm run preview` 或 `启动编辑器.bat` 启动，不要直接双击 `index.html`
- 打包产物部署到线上时 Vite 代理不存在，需自行配置后端代理转发（Key 也建议放后端），否则线上会再次遇到 CORS

    - styles/ 全局公共样式
  - components/ 通用 Vue 组件

  - utils/ 通用工具方法
  - App.vue 根组件
  - main.js 项目入口文件

## 内容组件
- 分隔线 (Divider)：实线/虚线/点线，可带中间文字
- 图标 (Icon)：emoji/字符，可选圆形或圆角方形背景
- 列表 (List)：**逐项编辑**（文字 + 跳转链接），无序 / 有序 / 无标记，自定义标记符号
- 表格 (Table)：**表头按列、数据按行逐项编辑**，斑马纹与配色可调
- 视频 (Video)：视频直链（mp4）或 iframe 嵌入
- 轮播图 (Carousel)：**每张图独立成组**（图片 + 说明文字 + 跳转链接），
  支持**选择本地图片**并随导出一起打包，多图自动/手动切换、指示点与左右箭头（导出时带交互脚本）

> 图片类内容支持「选择本地图片」：图片以 data URL 存在页面数据里（草稿刷新不丢），
> 导出时自动打包进 ZIP 的 `images/` 目录并重写路径，无需图床。
